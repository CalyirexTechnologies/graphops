05 · Evidence22

What is real, and what is not

Real
Every number in this deck is printed by the code.
The engine, the connectors and the command line run on Python with nothing installed.
Eight live connector paths run over HTTP in the tests, and CloudTrail from log files. Each must build the replay graph exactly.
Both engines run and are compared on every demo.
Not real
The business is invented, and the addresses route nowhere.
The recordings are written from each vendor's documentation. No real tenant has answered them yet.
Until 5 November the live paths had never run, and most were wrong. CrowdStrike still called an API retired in September 2025.
Louvain here is the local-moving phase only, and the code says so.
